# Model Card: Indonesian Medical NER Bootstrap

## Model Details

- Primary base model: `indobenchmark/indobert-base-p1`
- Comparator base model: `xlm-roberta-base`
- Task: token classification / named entity recognition
- Labels: `GEJALA`, `OBAT`, `DOSIS`, `DIAGNOSIS`, `ANATOMI`
- Primary model path: `models/indobert-medical-ner-id`
- Comparator model path: `models/xlm-roberta-medical-ner-id`

## Intended Use

This model is intended for research and portfolio demonstration of Indonesian
medical NER. It can help identify candidate spans for symptoms, medicines,
dosages, diagnoses, and anatomy mentions in short Indonesian health texts.

## Out-of-Scope Use

Do not use this model for clinical decision making, diagnosis, treatment
recommendations, patient triage, or medication safety checks.

## Training Data

The current training data is derived from a public Indonesian health-topic
dataset and expanded with silver BIO labels generated by rules and medical
lexicons.

The project now also includes a held-out human gold evaluation set in
`data/true_gold_300/gold_resolved.conll`. This set contains 300 texts annotated
by two independent human annotators and manually adjudicated after agreement
measurement. It should be treated as evaluation data, not as training data.

A human-aligned silver training set is available in `data/human_aligned_silver/`.
It excludes the 300 true-gold texts and follows the adjudication policy from
`data/true_gold_300/adjudication_notes.md`.

## Evaluation

The primary evaluation is now the manually adjudicated true gold set. It is
suitable for prototype research reporting, but it is not an industry-grade or
formal clinical validation.

True gold metrics:

| Model | Micro precision | Micro recall | Micro F1 |
| --- | ---: | ---: | ---: |
| IndoBERT human-aligned | 0.7967 | 0.6631 | 0.7238 |
| IndoBERT | 0.6538 | 0.2530 | 0.3649 |
| XLM-RoBERTa | 0.6367 | 0.2395 | 0.3481 |

F1 per entity:

| Entity | IndoBERT human-aligned F1 | IndoBERT baseline F1 | XLM-R F1 |
| --- | ---: | ---: | ---: |
| ANATOMI | 0.8333 | 0.5391 | 0.5197 |
| DIAGNOSIS | 0.8364 | 0.1905 | 0.1905 |
| DOSIS | 0.4706 | 0.0000 | 0.0000 |
| GEJALA | 0.6897 | 0.4184 | 0.3941 |
| OBAT | 0.6214 | 0.0970 | 0.0970 |

The previous silver benchmark produced much higher scores, for example IndoBERT
micro F1 0.9996. Those numbers are retained only as engineering bootstrap
evidence and must not be used as clinical performance claims.

## Limitations

- The human-aligned retraining substantially improves true-gold performance, but
  `DOSIS` still has low support and remains the weakest label.
- `GEJALA` and `OBAT` recall still need improvement for broader clinical text.
- The human-aligned silver data is rule-labeled, not manually annotated.
- Performance on long clinical notes, abbreviations, typos, and real hospital
  records is unknown.

## Recommended Validation Before Use

- Keep `data/true_gold_300/gold_resolved.conll` as the held-out benchmark.
- Add more manually reviewed training examples, especially for `DOSIS`, `OBAT`,
  and ambiguous symptoms.
- Evaluate public claims against the true gold set, not the silver set.
- Add a domain expert review for medical safety-sensitive labels.

## Public Dataset Search Note

A relevant DetikHealth medical NER corpus is described in the JAIC paper
`Medical Named Entity Recognition from Indonesian Health-News using BiLSTM-CRF
with Static and Contextual Embeddings`, but the article page indicates that the
download data is not yet available. This project therefore keeps a local manual
gold workflow and treats any rules or LLM-generated expansion as silver labels.
